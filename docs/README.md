# Documentation

Cette documentation accompagne la plateforme photo indépendante avec adaptateur WordPress.

## Principes

- Le domaine métier reste indépendant de WordPress.
- WordPress agit comme adaptateur de présentation/intégration.
- Les tests métier doivent fonctionner sans WordPress.
- Les infrastructures sont interchangeables.

## Organisation

- `adr/` : décisions d'architecture
- `architecture/` : règles techniques
- `quality/` : stratégie qualité/tests
- `roadmap/` : priorisation technique

# ADR-006 — Automatic classification is suggestion

## Status
Accepted

## Context
Les métadonnées EXIF, Lightroom ou IA peuvent être incorrectes.

## Decision
Toute classification automatique est considérée comme une suggestion.
Le photographe conserve le contrôle éditorial final.

## Consequences
- validation humaine ;
- rejet possible ;
- auditabilité ;
- correction manuelle ;
- confiance variable selon la source.

# Import Lightroom

## Objectif
Importer :
- photos ;
- métadonnées ;
- hiérarchies de mots-clefs ;
- collections ;
- informations EXIF.

## Important
Les informations Lightroom ne sont pas considérées comme une vérité métier absolue.

Le système génère des suggestions de classification.
Le photographe reste souverain.

## Flux
1. Import photo
2. Extraction EXIF
3. Import keywords Lightroom
4. Génération classifications suggérées
5. Validation ou correction utilisateur

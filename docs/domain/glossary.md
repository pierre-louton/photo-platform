# Glossaire métier

## Photographer
Propriétaire du catalogue photographique, des galeries et des collections.

## Gallery
Contexte éditorial propriétaire des photos.
Une galerie possède le cycle de vie des photos qu'elle contient.
La suppression d'une galerie entraîne la suppression des photos associées.

## Photo
Ressource photographique appartenant à une galerie.
Une photo peut être classifiée dans plusieurs collections.

## Collection
Vocabulaire éditorial transversal.
Une collection ne possède pas les photos.
Elle les référence via des classifications.

## Classification
Association métier entre une photo et une collection.
Une classification peut être :
- suggérée automatiquement ;
- validée manuellement ;
- rejetée ;
- créée manuellement.

## Taxonomy
Organisation évolutive des collections.
La hiérarchie peut changer dans le temps sans modifier les photos.

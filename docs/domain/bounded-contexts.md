# Bounded Contexts

## Gallery Management
Responsable :
- création des galeries ;
- import des photos ;
- publication ;
- archivage ;
- suppression.

Ownership principal :
Photographer -> Gallery -> Photo

## Cataloging / Classification
Responsable :
- collections ;
- taxonomie ;
- suggestions EXIF ;
- import Lightroom ;
- validation humaine ;
- reclassification.

Concept central :
Photo <-> Classification <-> Collection

## Media Storage
Responsable :
- stockage des originaux ;
- previews ;
- thumbnails ;
- hash ;
- CDN ;
- suppression physique.

## Publication
Responsable :
- visibilité ;
- accès ;
- partage ;
- API publique ;
- recherche.
